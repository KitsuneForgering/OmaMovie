# Architecture Decision Records

Decisões que afetam significativamente a arquitetura (CLAUDE.md §20). Cada ADR registra
contexto, decisão, alternativas e consequências. ADR aceito não é editado para mudar a
decisão: uma decisão nova substitui a antiga num ADR novo, que marca o anterior como substituído.
