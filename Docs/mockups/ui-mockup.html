    Clique dentro do mockup para usar o teclado. Alguns atalhos (como Ctrl+1) podem ser capturados pelo navegador; os botões fazem o mesmo.

    Experimente

    • Espaço play/pausa · J K L (repita para acelerar) · ← → quadro · ↑ ↓ corte anterior/próximo
    • Clique num clip e use a barra acima do viewer: Cor, Recorte (arraste o retângulo no viewer), Velocidade, Efeitos
    • Ctrl+B divide · Delete remove fechando o espaço · Shift+Delete deixa espaço · Ctrl+Z desfaz
    • Na biblioteca, selecione um item e use E (adicionar ao fim), W (inserir), Q (conectar como camada) · F favorita
    • Arraste as bordas dos clips · duplo clique numa junção abre o editor de corte · B lâmina, T trim, A seleção
    • Ctrl+K paleta de comandos · troque Janela para "Meia tela" para ver o layout em tiling
    • Efeito "Granulado" mostra o aviso de trecho fora do tempo real
