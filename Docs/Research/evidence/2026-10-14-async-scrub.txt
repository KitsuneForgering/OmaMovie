== libuv spike (scratch program, not committed; libuv 1.52.1 from the system)
A burst of 20 requests 15 ms apart; each request decodes 1..100 frames (uniform, seed 7) of
3 ms each, stopping between frames when superseded; 10 rounds, means.
  A oma::JobPool, one worker, Session's pattern (one in flight, one wanted, request counter)
  B uv_queue_work on libuv's pool, uv_cancel for queued work, the same counter for running
    work, publication in after_work on the loop thread
  C oma::JobPool FIFO without cancellation
A JobPool latest-wins : last request published after   171.5 ms,  147.5 frames decoded, 1 stale published
B libuv  latest-wins  : last request published after   171.8 ms,  149.3 frames decoded, 1 stale published
C JobPool FIFO        : last request published after  2879.6 ms, 1026.7 frames decoded, 190 stale published
"stale published" counts superseded requests that completed; the app's publication check drops
them. libuv cannot interrupt a running work callback, so B needs A's flag; B also adds libuv's
process-wide pool (4 threads by default) and a loop thread beside Qt's.
