# OmaMovie v0.1.0-rc.1

First public release candidate for Omarchy and current Arch Linux on x86_64. Please
try a real edit and report unclear steps, incorrect output or crashes in
[GitHub Issues](https://github.com/KitsuneForgering/OmaMovie/issues). Include the
OmaMovie version, hardware, source format and steps to reproduce when possible.

## Try it

The release provides a source archive and an x86_64 Linux application archive with
SHA-256 checksums. The application archive contains the installed `usr/` tree and uses
the system Qt, FFmpeg, Vulkan and other dependencies listed in `PKGBUILD`; it is not a
self-contained AppImage. On current Arch/Omarchy, building and installing the package
with `makepkg -si` is also supported. OmaStore can use the release archive once the
repository is indexed there.

On first launch, the tour opens a bundled editable demo. You can import local video,
audio and pictures; mark a source range; arrange and trim clips; add titles, looks and
transitions; preview with sound; save and reopen `.omamovie` projects; and export MP4,
Matroska or WebM using the profiles available in the installed FFmpeg build. The
Command Palette (`Ctrl+K`) lists actions and lets you remap shortcuts.

## Validation and scope

Automated edit, parser, recovery and GUI checks run in CI. Export correctness has been
checked against independently decoded output on Intel Iris Xe and the software path,
including reordered cuts, audio, a 25-minute edited movie and earlier two-hour runs.
The final RC gate checks the exact release commit before tagging.

Intel Iris Xe and the software path are the validated configurations. AMD, NVIDIA and
hybrid machines have not been validated. OTIO, FCPXML, EDL and MLT import support covers
documented subsets, not every project from those editors. Export still transfers
rendered frames through host memory before encoding. This candidate is for testing;
feedback on the first complete editing workflow will guide the stable v0.1 release.
